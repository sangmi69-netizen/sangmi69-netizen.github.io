12현 가야금 연주하기

창일중학교 이상미 · 온라인 가야금
뜯기
줄을 톡 누르면 그 줄이 울립니다. 빠르게 누를수록 조금 더 세게 소리 나요.
훑기
손가락을 대고 위아래로 쓱 훑으면 지나가는 줄이 차례로 촤라락 뜯깁니다. 세로 화면에서는 좌우로 훑으세요.
여러 줄
두 손가락 이상으로 여러 줄을 동시에 뜯을 수 있어요(옥타브·화음).
농현
안족(기러기발) 왼쪽을 누르면 음이 떨립니다. 줄을 뜯은 채 흔들어도 농현이 걸려요. 왼쪽으로 더 밀면 음이 올라갑니다(최대 온음).
조율
오른쪽 위 조율에서 산조 가야금(실음 G2–D5), 정악 평조, 정악 계면조를 고를 수 있어요.
표시
줄에 번호(1–12현), 율명·구음, 계이름(도레미), 음이름(C D E), 줄이름(산조 기보음)을 바꿔 붙일 수 있어요.
전체화면
오른쪽 위 ⛶를 누르면 화면 가득 연주 화면으로 바뀝니다.
키보드
PC에서는 1 2 3 … 0 - = 열두 키로 1현부터 12현까지 뜯을 수 있어요.
소리는 첫 터치에 켜집니다. 무음이면 아이폰 옆면의 무음 스위치를 확인해 주세요.
산조 가야금의 줄이름(기보음)은 실음보다 완전5도 위로 부르는 이름이라, 1현 줄이름은 ‘레’이지만 실제로는 G2(솔)로 울립니다.
정악 조율은 휴대폰 스피커에서 잘 들리도록 실제보다 한 옥타브 높게 울리게 했습니다.
